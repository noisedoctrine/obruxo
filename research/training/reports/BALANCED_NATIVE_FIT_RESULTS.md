There is a training/export mismatch to investigate before another long run. The current fixed logit scales affect both the sampled forward category and the parameter control's cross-entropy. In the first original-input block, the sound-loss forward sample selects the source unison category on only 26/64 updates, although the starting production argmax is correct on all 64 original inputs. Source-category agreement is diagnostic, not a requirement to recover a unique patch. Lowering Gumbel temperature changes its derivative but does not change the hard selected category for fixed logits and noise. The four contiguous view blocks also finish with 64 updates using only alternate-pattern inputs. Neither observation establishes the cause of the sound regression.

Next qualify a training path that renders the actual production category choice while keeping a usable backward derivative, and compare reciprocal input views within updates rather than leaving them in separate long blocks. Keep raw category logits for the parameter control. A changed adapter needs explicit derivative/export checks and a bounded native-direction check before any full fit; the old adapter's passed check is historical evidence, not qualification of a new path. Keep the current sound objective, compact model, accepted starting weights and unchanged original/wider gates. No more parameter-only initializer retries.
