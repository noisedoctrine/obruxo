# Preserve inference attribution and runtime notices

Local snapshots previously included readmes but omitted the pinned Basic Pitch license/attribution text. Snapshots now carry the original Spotify LICENSE and NOTICE plus nnAudio's MIT text. [Upstream records](../notices/upstream/manifest.json) bind their source revisions, URLs and exact byte hashes; Git preserves their original line endings. The [scope note](../notices/README.md) describes OBRUXO's conversion and separates upstream attribution from installed dependencies.

The [locked runtime inventory](data/inference_runtime_notices.json) preserves **68 original license/notice files across all 36 distributions**, plus the exact wheel-hash lock. It occupies **1.20 MiB**. Every text matches its installed distribution's RECORD, and every declared license file and locked version is covered. Missing license expressions remain unspecified. The collector neither installs packages nor modifies the runtime. Its selector distinguishes the `packaging/licenses` code package from metadata license texts; a regression test covers generated Python caches.

Implementation `65f69a4` precedes the [real snapshot check](data/inference_notice_bundle_plan.json). The new snapshot binds the full notice inventory and three frontend attribution texts into its file manifest. In the existing fresh Windows/Python environment, one already audited held-note input produces **exactly the same preset bytes**. All dependency modules and model math libraries remain inside that environment. [Measured result](data/inference_notice_bundle_summary.json): **21.17 seconds / 0.94 GiB RAM / 6.88 MiB evidence**, within five minutes / 4 GiB / 128 MiB. This is packaging evidence on a previously tested input, not reconstruction improvement.

Twenty-one focused notice/snapshot tests pass, including isolated inference for all three supported artifact formats, copied attribution bytes, runtime inventory binding, changed RECORD files, missing packages/texts and recomputed manifests with missing file coverage. Ruff and diff checks pass. All numerical source files pinned by the concurrent direct-control experiment remain unchanged. There are zero new native renders or optimizer applications.

Full release notices remain unfinished: the repository has no selected project-wide license file, and copied Vital initialization/schema data require resolution against their recorded provenance. This change collects and preserves notices; it does not select the owner's license or certify distribution permission. Snapshots and inventories keep `release_notices_complete=false`; all model-quality, listening and release gates remain required.
