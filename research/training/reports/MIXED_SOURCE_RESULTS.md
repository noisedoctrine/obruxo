# Mixed original-source training and validation

The [plan](data/mixed_sources_plan.json) and [result](data/mixed_sources_summary.json) pass all fifteen qualification gates. The private mixture contains 1,724 training states (904 corpus and 820 authored) and 239 validation states (131 corpus and 108 authored). The union retains all 10,616 assignments from the two original ledgers. There are no scheduled final-test entries.

The [alias census](data/mixed_sources_aliases.json) checks all 2,177 statically eligible source programs, including reserved sources only for static split isolation. It finds 2,175 canonical programs, two alias groups and no cross-split aliases. It changes no source assignments, scalar controls, phase values or seed bits. Same-split aliases and existing authored variants share evaluation groups. This is a declared program-canonicalization check before lossy encoding, not an acoustic or general near-duplicate census.

The [compatibility receipt](data/mixed_sources_compatibility.json) verifies source artifact IDs and exact frozen parent manifests. Every one of the 820 authored training entries retains its target and supervision masks under the mixture's model. The inherited authored coverage therefore remains represented: 775 scalar fields, 769 varied supervised controls, all registered asset choices, eight LFOs, custom curves and seed slots, all 64 connection slots, 32 sources and 431 destinations. These are preserved supervision declarations; the earlier native destination checks are not new audibility or learning results for the mixture.

The full attempted epoch alternates sources, with 904 attempts from each source and every training state visited. The smaller authored group cycles only after visiting every authored state. QA outcomes do not change this schedule. The bounded actual run makes nine attempts and retains eight distinct examples: five authored and three corpus. One corpus view is rejected for `audio.clipping` and remains recorded, with no dataset removal or patch-control edits. Equal attempt proportions do not imply equal accepted replay proportions.

All eight accepted sources reach native rendering as original documents and pass 775-control/six-family readback. They supply audio-only features to three training updates. Optimizer recovery from step one exactly matches model, optimizer, RNG, batch RNG, replay and cursor, without further renders. Four validation cases (two per source) pass native ingestion and exact fixed-phase repeats, eight successful validation requests. Their features are computed after training and never enter replay or optimization. The frozen Basic Pitch checks and model export/reload pass.

Peak process-tree memory is 2,734,231,552 bytes (2.55 GiB), within the 8 GiB budget. The qualification takes 277.21 seconds including source-metadata loading, supervision comparisons, actual renders/features, optimizer work, recovery and held-out ingestion. Metadata loading takes 67.69 seconds on this machine. The initial eager builder rebuilt authored sources before its program census; that obsolete run was stopped. The mixed path now validates metadata at startup, inspects each source once during building, and verifies source identity/labels before each render. The original authored loader retains full verification by default.

The 35-test regression run passes, covering mixed manifests/aliases, both validation sources, attempted-source balance, full epoch coverage, source/artifact corruption, reserved-test rejection, deferred source verification, exact recovery/export, legacy pools and longer observations. Final focused checks repeat source guards and scheduling, with the evaluator checked for lineage-grouped plans. Ruff and whitespace checks pass. Dataset paths, presets, features, audio and weights remain private; public evidence is metadata only.
