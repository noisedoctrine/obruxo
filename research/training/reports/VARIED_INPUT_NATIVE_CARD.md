# Native check before varied-input initialization

Declared before native execution on 2026-10-22. The [varied sampler](../VARIED_INPUTS.md) keeps the basic 14-output model and gives each patch a two-second held note plus a category-balanced alternate pattern. Check that these new performances render cleanly and reproducibly before spending the initialization budget. This is pipeline validation, with no learning or model-quality claim.

Select one training patch from each of the six source categories and three alternate-pattern cells: 18 patches. Within each cell choose the highest oscillator-level source, breaking ties by state ID, to stress legal levels under chords and unison. Render its actual sampler-generated held and alternate views twice: 36 observations and 72 requests. Re-render the first four original full-bootstrap source requests and compare their audio hashes against the independently audited receipts. Total: **76 native requests, zero optimizer updates**. No validation or test state is used.

Keep the qualified native engine, fixed phases for oscillator 1–3 and sampler, 32,768-frame lead, existing audio QA and one fresh isolated worker per request. The worker uses the existing lightweight native factory; the parent durably charges each attempt before starting it. The four historical hashes must stay exact, so reducing worker import overhead cannot silently change rendering. Retain request IDs, source identities, repeat hashes, QA and cost evidence; discard audio after checking it.

The [public request manifest](data/varied_input_native_plan.json) records all source/request identities, limits and the expanded execution plan's ID/file hash. Embedded preset payloads stay in private evidence to avoid duplicating 13 MiB of presets in Git. Execution plan ID: `d885558107bc19b4fb74bde83fd7d49f851ddbb1d7e10e8f8305b61997e89ea5`. Freeze the executed source commit before rendering. Require every request to pass unchanged QA, all 36 repeat pairs to have identical float32 audio hashes, all four historical hashes to match, and completion within **10 minutes, 4 GiB process-tree RAM and 64 MiB evidence**. Report the full sampler's pattern counts and pitch coverage separately from this selected native subset. A failed request remains charged. Recovery keeps the original deadline and refuses failed, changed or unresolved history; no automatic retry or extension.

Passing admits only a separately costed varied-input initialization comparison. It does not pass A2, establish held-out reconstruction, authorize a new output family or promote a model.
